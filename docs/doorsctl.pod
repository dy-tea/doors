=head1 NAME

doorsctl - The IPC client for the doors Wayland compositor.

=head1 SYNOPSIS

doorsctl [I<L<command|"COMMANDS">>] [I<subcommands>]... [I<options>]...

=head1 DESCRIPTION

I<doorsctl> communicates with the running doors compositor over IPC.
The IPC socket used is set by the I<$DOORS_SOCKET> environment variable.
It is used to both configure the running compositor as well as perform
actions such as moving toplevels, setting layouts, or changing focus.
Events can also be subscribed to, and hotkeys can be changed (although
this is simplified in the L<doorshkrc(5)> file).
Note that a running doors compositor is required for commands to function.

=head1 COMMANDS

I<command> is one of the top-level commands, which include: L</"bezier">,
L</"commands">, L</"config">, L</"desktop">, L</"env">, L</"focus">,
L</"globalshortcuts">, L</"hotkey">, L</"input">, L</"layer_rule">,
L</"layout">, L</"node">, L</"output">, L</"permission">, L</"plugin">,
L</"query">, L</"quit">, L</"resize">, L</"rule">, L</"scratchpad">,
L</"seat">, L</"send">, L</"sessions">, L</"spring">,
L</"subscribe">, L</"swap">, L</"toggle">, L</"tree"> and L</"wm">.

=over 4

=item bezier

C<doorsctl bezier [I<name>] [I<p1x>] [I<p1y>] [I<p2x>] [I<p2y>]>

Register named cubic bezier curves for use as animation easing functions.
The curve is defined by two control points, with implicit I<P0>=(0,0) and
I<P1>=(1,1).

I<name> is the name of the bezier (e.g. "linear"),I<p1x> I<p1y> are the
position of point 1, I<p2x> I<p2y> are similarly the position of point
2 (these are floats).

=item commands

C<doorsctl commands>

Print out a list of all top-level commands and their subcommands.

=item config

C<doorsctl config [I<name>] [I<value>]...>

Get, set or reset a compositor setting. Run C<doorsctl config --list> to print
every setting with its type, current value, default and accepted range.


=over 4

=item I<--list>

C<doorsctl config --list [--json] [--changed] [--no-header]>

List settings. C<--json> emits JSON, C<--changed> only shows settings
differing from their defaults, C<--no-header> omits the header row.

=item I<--reset>

C<doorsctl config --reset [I<name>]...>

C<doorsctl config reset [I<name>]...>

Put settings back to their built-in defaults. With no names, resets every
setting that differs from its default.

=item I<animation>

C<doorsctl config animation [I<type>] [bezier|duration|spring|enabled] [I<value>]>

Configure per-type animation settings. Types include C<geometry>, C<resize>,
C<fade_in>, C<fade_out>, C<fade_in_layer>, C<fade_out_layer> and
C<workspace_slide>.

=item I<animation_bezier>

C<doorsctl config animation_bezier [I<name>]>

C<default>.

=item I<animation_duration>

C<doorsctl config animation_duration [I<ms>]>

Get or set the global default animation duration in milliseconds. Defaults to
C<180>.

=item input

C<doorsctl input [I<device>] [type:I<type>] [I<property>] [I<value>]>

Set an input device property. Use C<*> for all devices.

I<device> is the device name as reported by the compositor. Alternatively
use C<type:*> to target a whole class of devices.

I<type> is one of C<keyboard>, C<pointer>, C<touchpad>, C<touchscreen>,
C<tablet>, C<tablet_pad>, C<switch> or C<any>. A touchpad is detected
automatically and matches both the C<touchpad> type and the C<pointer> type.

The property C<xcursor_size> takes no device or type and sets the cursor theme
size (1-512) globally.

=item layer_rule

C<doorsctl layer_rule -a|--add I<namespace> [output=I<pattern>] [options...]>

C<doorsctl layer_rule -r|--remove I<index>>

C<doorsctl layer_rule -l|--list>

Manage layer-shell surface rules. Layer surfaces are matched by their
namespace and optionally by output (unlike toplevels they have no title).
Patterns accept C<exact:>, C<glob:>, C<regex:> and the C<i:> caseless prefix.

Consequences are C<blur=on|off>, C<opacity=0-1>, C<animations_disable=on|off>,
C<keyboard_interactivity=none|exclusive|on_demand>,
C<layer=background|bottom|top|overlay>, and
C<block_out_from_screenshare=on|off>. Rules apply when a layer surface is
created. Blur also requires blur to be enabled.

=item scroller settings

C<doorsctl layout scroller always_center_single_column [true|false]>

C<doorsctl layout scroller center_focused_column [never|always|on_overflow]>

C<doorsctl layout scroller right_strut [I<px>]>

C<doorsctl layout scroller bottom_strut [I<px>]>

C<doorsctl layout scroller pan_fingers [I<n>]>

C<doorsctl layout scroller snap_percent [I<n>]>

C<doorsctl layout scroller default_column_width [I<proportion|px>]>

C<doorsctl layout scroller preset_column_widths [I<values>]>

C<doorsctl layout scroller preset_window_heights [I<values>]>

The struts reserve space at a screen edge, I<pan_fingers> defaults to
C<3>, and I<snap_percent> to C<30>. I<default_column_width> is what new
columns get, and the presets are the comma separated proportions or
C<px> sizes that C<cycle_width> and C<cycle_height> step through.
