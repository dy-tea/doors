=head1 NAME

doorsctl - The IPC client for the doors Wayland compositor.

=head1 SYNOPSIS

doorsctl [I<L<command|"COMMANDS">>] [I<subcommands>]... [I<options>]...

=head1 DESCRIPTION

I<doorsctl> communicates with the running doors compositor over IPC.
The IPC socket used is set by the I<$DOORS_SOCKET> environment variable.
It is used to both configure the running compositor as well as perform
actions such as moving toplevels, setting layouts, or changing focus.
Events can also be subscribed to, and hotkeys can be changed (although
this is simplified in the L<doorshkrc(5)> file).
Note that a running doors compositor is required for commands to function.

=head1 COMMANDS

I<command> is one of the top-level commands, which include: L</"bezier">,
L</"commands">, L</"config">, L</"desktop">, L</"env">, L</"focus">,
L</"globalshortcuts">, L</"hotkey">, L</"input">, L</"keyboard_grouping">,
L</"master_stack">, L</"node">, L</"output">, L</"permission">, L</"query">,
L</"quit">, L</"resize">, L</"rule">, L</"scratchpad">, L</"scroller">,
L</"seat">, L</"send">, L</"sessions">, L</"spring">, L</"subscribe">,
L</"swap">, L</"toggle">, L</"tree"> and L</"wm">.

=over 4

=item bezier

C<doorsctl bezier [I<name>] [I<p1x>] [I<p1y>] [I<p2x>] [I<p2y>]>

Register named cubic bezier curves for use as animation easing functions.
The curve is defined by two control points, with implicit I<P0>=(0,0) and
I<P1>=(1,1).

I<name> is the name of the bezier (e.g. "linear"),I<p1x> I<p1y> are the
position of point 1, I<p2x> I<p2y> are similarly the position of point
2 (these are floats).

=item commands

C<doorsctl commands>

Print out a list of all top-level commands and their subcommands.

=item config

C<doorsctl config [I<name>] [I<value>]...>

Get, set or reset a compositor setting. Run C<doorsctl config --list> to print
every setting with its type, current value, default and accepted range.


=over 4

=item I<--list>

C<doorsctl config --list [--json] [--changed] [--no-header]>

List settings. C<--json> emits JSON, C<--changed> only shows settings
differing from their defaults, C<--no-header> omits the header row.

=item I<--reset>

C<doorsctl config --reset [I<name>]...>

C<doorsctl config reset [I<name>]...>

Put settings back to their built-in defaults. With no names, resets every
setting that differs from its default.

=item I<animation>

C<doorsctl config animation [I<type>] [bezier|duration|spring|enabled] [I<value>]>

Configure per-type animation settings. Types include C<geometry>, C<resize>,
C<fade_in>, C<fade_out>, C<fade_in_layer>, C<fade_out_layer> and
C<workspace_slide>.

=item I<animation_bezier>

C<doorsctl config animation_bezier [I<name>]>

Get or set the global default bezier curve for animations. Defaults to
C<default>.

=item I<animation_duration>

C<doorsctl config animation_duration [I<ms>]>

Get or set the global default animation duration in milliseconds. Defaults to
C<180>.

=back
